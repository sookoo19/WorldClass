## 1. サービス概要

### コンセプト

日本国内のご家庭・個人塾・サークル団体・公民館・図書館等と、発展途上国の学校や現地で活動する日本人をつなぐオンライン国際交流マッチングプラットフォーム。文化交流・英語学習・国際理解を1セッションで同時に実現する。セッション料金の一部を物資支援として現地の教育施設へ還元し、教育格差の縮小にも貢献する。

### 登場人物（アクター）

日本側の利用者は単一の概念「利用者（member）」として扱い、`type`（ご家庭 / 個人塾 / サークル団体 / 公民館・図書館 / その他）で区分する。「ご家庭」は個人、それ以外は法人寄りの団体だが、DB・登録フローは共通化する（→ [DB設計](2026-05-29-worldclass-db-design.md)）。

| アクター                                                       | 役割                                                                     |
| -------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 利用者・ご家庭（個人）                                         | オープンセッション（相乗り）にグループ単位で参加申込                     |
| 利用者・団体（個人塾／サークル団体／公民館・図書館／その他）   | 専用セッションを任意日時で予約・実施                                     |
| 自治体・教育委員会（将来フェーズ）                             | 一括年間ライセンス契約→管内へ展開                                       |
| 海外パートナー（海外校／現地で活動する日本人）                 | 交流セッション提供                                                       |
| 運営（WorldClass）                                             | プラットフォーム管理・物資調達・発送・パートナー審査・オープンセッション設定 |

### 価値提案

| アクター                   | 価値                                                                   |
| -------------------------- | ---------------------------------------------------------------------- |
| 利用者・団体（塾等）       | 文化交流・英語学習・国際理解を1セッションで実現。テンプレで準備負荷低  |
| 利用者・ご家庭             | 低価格でリアルな異文化・英語体験。申込はオープンセッションを選ぶだけ   |
| 海外パートナー（校・日本人）| 物資支援（教材・文具・機材等）。現金不要で公平                         |
| 自治体（将来）             | 一括契約でコスト効率。ダッシュボードで国際教育実績を自己出力可能       |
| 運営                       | セッション手数料＋自治体ライセンス料                                   |

## 2. コアフロー

### 利用者タイプ別フロー概要

```
利用者・団体（個人塾・サークル団体・公民館・図書館・その他）
  └─ カタログから海外パートナーを選択 → 任意の日時で専用セッション予約

利用者・ご家庭
  └─ 運営が設定したオープンセッションにグループ単位で参加申込（相乗り方式）
```

### 団体ユーザーフロー

```
1. 登録
   └─ 組織情報・担当者名・学年（個人は氏名・子どもの年齢）

2. カタログ検索
   └─ フィルタ：国・テーマ・学年・時間帯
   └─ ※言語フィルタなし（全校英語対応が前提）
   └─ 海外パートナープロフィール閲覧（紹介VTR・評価スコア・物資支援実績）

3. セッション予約
   └─ 日時選択
   └─ テンプレ選択（文化交流 / 国際理解 / 英語学習）
   └─ カスタマイズ（質問リスト・テーマ絞り込み・セッション時間）

4. 決済
   └─ セッション単位
   └─ 料金内訳を透明表示（運営手数料○% / 物資支援○%）

5. 準備フロー
   └─ 1週間前まで：利用者が質問リスト・要望を送信
   └─ 3日前まで：海外パートナーが「準備完了」チェック
        └─ 未チェック → 運営がアラート・催促
   └─ 1日前12時まで：それでも未確認 → 自動キャンセル・全額返金
        └─ 利用者に通知 ＋ 次回セッション10%割引クーポン付与

6. セッション実施
   └─ Zoom等（プラットフォーム外）で実施
   └─ 前日リマインド・当日チェックリスト提供

7. 事後
   └─ 利用者が準備評価（★1〜5）を提出
   └─ 物資支援レポート（四半期/半年ごと）を受取
```

### ご家庭フロー（オープンセッション）

```
1. 登録
   └─ 氏名・メール・子どもの年齢

2. オープンセッション一覧を閲覧
   └─ 運営が設定した固定日程（例：毎週土曜10時・ケニア校・文化交流）
   └─ 残枠数・テーマ・対象年齢・参加費を表示

3. 参加申込・決済（グループ単位）
   └─ 3グループ以上で成立確定（最低グループ数に達したら確定通知）
   └─ 最低グループ数未達の場合：自動キャンセル・全額返金

4. 準備フロー
   └─ 1週間前まで：質問・リクエストを送信
   └─ 1日前12時：海外パートナーから準備完了確認
        └─ 未確認 → キャンセル・全額返金・次回10%割引クーポン付与

5. セッション実施（Zoom等）

6. 事後
   └─ 評価（★1〜5）提出
   └─ 物資支援レポート受取
```

### 海外パートナーフロー（海外校／現地で活動する日本人）

```
1. 登録申請 → 運営審査
2. プロフィール・空き時間登録
3. セッション実施
4. セッション後：物資申請リスト送信（四半期/半年ごと）
5. 物資受取 → 受領写真送信 → 運営が利用者へ通知
```

## 3. 物資支援の仕組み

### 積算・発送サイクル

```
セッション料金の50% → 海外パートナーごとに物資ポイントとしてプール

四半期 or 半年に1回：
  └─ 海外パートナーが物資リスト申請（教育用途のみ）
  └─ 運営が現地調達 or 提携NGO経由でまとめて手配
       └─ 現地調達優先（配送コスト削減）
  └─ 受領確認写真を海外パートナーが送信
  └─ 運営が写真＋支援レポートを利用者へ通知
```

### 管理ルール

- 物資は教育用途のみ（文具・教材・PC・プロジェクター等）
- 現金のやり取りなし（着服リスク排除）
- プール残高は海外パートナーごとにダッシュボードで可視化
- 未使用分は翌期繰越

## 4. 海外パートナーオンボーディング・品質管理

### 登録審査

```
1. 学校実在確認（書類・写真・ビデオ通話）
2. 担当教師が自己紹介VTR提出（2〜3分）
   └─ 英語流暢さ・カメラ映り・声の明瞭さを運営が確認
   └─ VTRはカタログ掲載の紹介動画として流用
   └─ NGなら再提出 or 不承認
3. 承認後カタログに掲載
```

### プロフィールページ（利用者が閲覧）

- 学校紹介動画（1〜2分）
- 国・地域・生徒年齢層
- 対応テーマ一覧
- 準備評価スコア（★）
- 過去の物資支援実績（写真付き）

### 品質維持ルール

| 状況                    | 対応                   |
| ----------------------- | ---------------------- |
| 準備評価★2以下が3回連続 | カタログ非表示         |
| 当日ドタキャン          | ペナルティポイント蓄積 |
| ペナルティ3回           | アカウント停止         |

## 5. テンプレート・授業設計

運営が提供するテンプレ。利用者がカスタマイズして使用。

### A) 文化交流テーマ

- トピック：食・祭り・学校生活・家族
- 構成：自己紹介10分 → テーマ発表15分 → Q&A10分

### B) 国際理解テーマ

- トピック：貧困・教育・環境・水問題
- 構成：現地の実情紹介20分 → ディスカッション15分

### C) 英語学習テーマ

- トピック：英会話練習・発音・日常表現
- 構成：フレーズ練習15分 → ロールプレイ20分

### カスタマイズ範囲（利用者）

- 質問リスト追加
- テーマの絞り込み
- セッション時間（45分 or 60分）

## 6. 収益モデル・料金設計

### セッション料金

**利用者・団体（個人塾・サークル団体・公民館・図書館・その他）専用セッション**

| セッション時間 | 基本料金 | ファシリテーターオプション | 合計（オプション込み） |
| -------------- | -------- | -------------------------- | ---------------------- |
| 45分           | 8,000円  | +2,500円                   | 10,500円               |
| 60分           | 10,000円 | +3,000円                   | 13,000円               |

**利用者・ご家庭（オープンセッション・相乗り／グループ単位）**

| セッション時間 | 料金（仮）     | ファシリテーター     |
| -------------- | -------------- | -------------------- |
| 45分           | 2,500円/グループ | 料金込み（常時付き） |
| 60分           | 3,000円/グループ | 料金込み（常時付き） |

※3グループ以上で成立。料金は市場調査・競合分析後に調整

### ファシリテーターオプション（法人専用）

運営スタッフが通訳兼司会として参加するオプション。

| 項目             | 内容                                                             |
| ---------------- | ---------------------------------------------------------------- |
| 対象             | 利用者・団体の専用セッションのみ                                 |
| 役割             | 日英通訳 ＋ セッション進行（時間管理・Q&A整理）                  |
| 選択方法         | 予約 Step 3（テンプレ選択画面）でチェックボックス選択            |
| スタッフアサイン | 現時点は手動（Filament管理画面から担当者が確認・アサイン）       |
| 将来対応         | スタッフカレンダーとの連携による自動アサインを将来フェーズで検討 |

**オープンセッションについて**  
ご家庭向けのオープンセッションはファシリテーターが常時参加する前提で料金を設定。追加選択は不要。

### 料金内訳

**基本セッション料金（例：10,000円）**

| 区分           | 金額    | 比率 |
| -------------- | ------- | ---- |
| 運営手数料     | 5,000円 | 50%  |
| 物資支援プール | 5,000円 | 50%  |

**ファシリテーターオプション料金（例：+3,000円）**

| 区分               | 金額    | 比率 |
| ------------------ | ------- | ---- |
| スタッフ稼働コスト | 3,000円 | 100% |

※ファシリテーター料金は物資支援プールに含めない（スタッフコスト専用）  
※基本料金の比率は原価計算後に調整

### 自治体・教育委員会向けライセンス

- 年間ライセンス（管内学校数×割引単価）
- 一括契約で単価10〜20%割引
- 専用ダッシュボード提供
    - セッション数・参加人数・物資支援実績を閲覧
    - CSV/PDF自己出力対応

## 7. 対象国・言語

- **対象国（提携予定）:** ケニア・ブータン・モロッコ・東ティモール・ガーナ・チュニジア（他、複数国と連携協議中）
- **言語:** 英語を基本とする（言語フィルタなし）。現地で活動する日本人パートナーは日本語での交流も可
- **将来拡張:** 対象国の追加・多言語対応は将来フェーズで検討

## 8. 技術スタック・アーキテクチャ方針（確定）

詳細は [`engineering-principles.md`](2026-05-25-worldclass-engineering-principles.md) を参照。

| 項目               | 決定内容                                                        |
| ------------------ | --------------------------------------------------------------- |
| **バックエンド**   | Laravel 13 + Filament v4（管理画面）                            |
| **フロント**       | Inertia.js + React（SPA的UX、API不要）                          |
| **アーキテクチャ** | フルレイヤー分離（Domain / UseCase / Repository / Controller）  |
| **Docker**         | カスタム Docker Compose（PHP 8.3 + Nginx + PostgreSQL + Redis） |
| **テスト**         | TDD（Pest）— UseCase・Repository はテストファースト             |
| **コード原則**     | SOLID原則を明示的に適用                                         |
| **コミット規約**   | Conventional Commits（`feat:` `fix:` `refactor:` 等）           |
| **CI/CD**          | GitHub Actions（テスト + Pint + Larastan）                      |
| **env管理**        | `.env.example` のみgit管理、Secrets は GitHub管理               |

## 9. 未決定事項（要検討）

- セッション料金の具体的単価（競合調査必要）
- 物資支援の手数料比率（50/50は仮設定）
- 提携NGO・現地調達パートナーの選定
- キャンセルポリシーの詳細（天災・回線障害等の例外）
- 海外パートナー教師への個人報酬の扱い（物資のみで十分か）
