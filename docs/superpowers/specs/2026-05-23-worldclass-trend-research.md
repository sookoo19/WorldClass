# WorldClass 市場トレンド調査レポート

**作成日:** 2026-05-23  
**対象:** WorldClass サービス設計書に基づく市場・競合・機会・リスク分析

---

## 1. 市場規模

- 日本の教育DX/ICT市場：2030年度に**6,113億円**（2023年度比2.6倍）予測（富士経済グループ）
- 語学ビジネス市場：2024年度**7,906億円**（前年度比100.2%）
- WorldClassの細分市場（学校向けオンライン国際交流）は独立データなし
  - 全国公立小中高校 約3万校の**5%普及時で24〜60億円ポテンシャル**（1校年間2〜4セッション試算）
  - 市場は「創造期」でWithTheWorld等が形成しつつある段階

---

## 2. 政策トレンド（追い風）

### 第4期教育振興基本計画（2023〜2027年度）
- 「持続可能な社会の創り手育成」＋「ウェルビーイング向上」が二本柱
- WorldClassのコンセプトと政策方向性が強く一致

### 英語教育強化
- 令和7年度概算要求：英語教育強化に**550百万円**計上
- 高校卒業時CEFR A2以上6割達成を目標値に設定
- 生成AI活用の英語力向上を複数自治体で実証中（草津市・鳥羽市・新地町）
- 英語を「話す・伝える」アウトプット重視に政策転換→ネイティブとのリアル会話需要増大

### 国際交流促進
- 2033年までに日本人高校生の海外留学**12万人**（現状の約2倍）を数値目標
- コロナ禍で断絶した海外交流の代替・補完としてオンライン交流が政策的に後押し

### SDGs教育
- 文科省がESD（持続可能な開発のための教育）を推進
- 学習指導要領にSDGsの視点が組み込み済み→教育現場での需要が制度的に確立

### NEXT GIGA（2024〜2028年度）
- 端末更新・ネットワーク整備に**総額2,643億円超**を投入
- 全校に高速インターネット・1人1台端末整備完了見通し
- **オンライン国際交流のインフラ障壁がほぼ解消**

## 3. 競合分析

### 国内競合マップ

| プレイヤー | 双方向性 | 途上国交流 | 社会貢献機能 | 自治体実績 | 料金 |
|---|---|---|---|---|---|
| **WithTheWorld** | 高 | 一部あり | なし | あり | 非公開（高め） |
| **ぼらぷら** | 中 | あり（カンボジア） | あり（ボランティア） | 一部 | 99,800円〜（個人） |
| **JICA** | 低（講座型） | あり | あり | あり | 無料 |
| **WorldClass（想定）** | 高 | あり（設計上） | あり（物資還元） | - | 8,000〜10,000円/回 |

### 各競合の詳細

**WithTheWorld（最大手・直接競合）**
- 67カ国・546校以上のネットワーク
- 鹿児島県教育委員会・泉南市など自治体との契約実績あり
- 90〜100分のPBL型セッション
- 弱点：発展途上国への収益還元機能なし・SDGs訴求が薄い

**ぼらぷら**
- カンボジアの村とライブで繋ぐオンライン研修
- SDGs×ボランティア文脈で差別化
- 弱点：主に高校生以上が対象。小中学校向けカリキュラムが弱い

**JICA**
- オンライン出前講座を無料提供
- 信頼度・認知度が高い
- 弱点：双方向性低い・単発講座・英語アウトプット機会が少ない
- 競合というより「有料継続サービスへのステップ」として存在

## 4. WorldClassの差別化ポイント

### 1. セッション収益の物資還元モデル
- **既存競合にこの仕組みを持つプレイヤーは存在しない**
- 教育機関・自治体がSDGs関連予算の執行を正当化しやすいナラティブ
- 購買決定者（校長・教育委員会・自治体議員）への説明責任を果たしやすい

### 2. 公民館・図書館・自治体施設への展開
- 競合は学校（中学・高校）に特化
- 公民館・図書館は生涯学習予算（教育委員会社会教育課）からの調達ルートを開く
- **競合が参入しにくいブルーオーシャン領域**

### 3. 小学校 × 英語教育 × SDGsの三位一体
- 2020年度から小学校で英語教科化完全実施
- JICAは無料だが「英語で話す」実践機会が少ない
- WithTheWorldは中学以上が中心
- **小学校向けの設計を明確にすることで競合空白地帯を先占できる**

### 4. 海外パートナー校の審査・品質管理機能
- 審査済みパートナー校との「安心保証」が自治体・教育委員会の導入障壁を下げる
- 個人情報保護・安全配慮義務の観点から強力な訴求点

### 市場機会のタイミング
- NEXT GIGAによるインフラ整備が2024〜2028年度に完了
- **「コンテンツ需要が爆発するタイミング」が今後2〜3年**
- 2026〜2027年度を自治体ライセンス展開の主戦場として設定が合理的

## 5. リスク分析

| リスク | 内容 | 対策 |
|---|---|---|
| **海外インフラ不安定** | 途上国の電力・通信品質が低い地域でのセッション品質保証が困難 | フィリピン・東南アジア（接続安定）から開始し段階的に拡大 |
| **物資調達オペレーション負荷** | 調達・発送・通関・受け取り確認が複雑 | NGO・JICAとの連携、現地ハブ組織の活用が必須 |
| **JICA等の無料競合** | 無料・高信頼の競合が存在する | 継続性・双方向性・英語アウトプット量の優位を具体的に示す |
| **個人情報・安全配慮義務** | 未成年の映像・音声の漏洩リスク、不適切コンテンツリスク | 保護者同意フロー必須、映像配信のセキュリティ設計、パートナー校のバックグラウンドチェック |
| **為替・地政学リスク** | 政情不安・通信インフラ国家管理で継続困難になるリスク | 複数地域・複数国のパートナー分散 |

## 6. 自治体・教育委員会への営業戦略

### 調達の現実
- 年度予算制のため、**8〜9月（概算要求時期）に働きかけが必要**
- 調達は一般競争入札・企画競争入札が基本
- 意思決定：学校長 → 教育委員会指導主事 → 教育長 → 首長（大型案件）

### 勝ちパターン

**1. パイロット無償提供 → 実績化 → 自治体ライセンス展開**
- 1〜2校に無償または低価格でパイロット導入
- 評価結果・生徒の変化・教員の感想をエビデンス文書化
- 実績を持って教育委員会・首長部局にアプローチ

**2. EDU-Portニッポンへの応援プロジェクト申請**
- 文科省・経産省・外務省・JICA連携の認定制度
- 取得できれば公的なお墨付きが得られ自治体提案が格段にしやすくなる
- **最優先で検討すべきアクション**

**3. SDGsブリーフィング**
- 地方創生SDGs官民連携プラットフォーム（内閣府）のマッチングイベントに参加
- 自治体の「SDGs未来都市」認定・「地方創生」施策との接続で提案説得力を高める

**4. ボトムアップ営業**
- 英語主任・国際理解担当教員を口説く
- 学校内部からの需要を生み出し教育委員会を動かす

**5. 年間パッケージ設計**
- 1校あたり年間6セッション＋コーディネーター伴走付きで提案
- 自治体が複数校に一括適用しやすい調達単位に設計

## 7. 優先アクションまとめ

| 優先度 | アクション |
|---|---|
| ★★★ | EDU-Portニッポンへの応援プロジェクト申請（公的認知獲得） |
| ★★★ | 小学校向けカリキュラムの設計（競合空白地帯の先占） |
| ★★★ | NGO・現地組織との提携交渉（物資オペレーション構築） |
| ★★ | フィリピン・東南アジアの海外パートナー校を先行確保 |
| ★★ | 1〜2自治体でのパイロット実証 → 実績データ取得 |
| ★ | 物資還元の「見える化」レポーティング設計（自治体の説明責任対応） |
