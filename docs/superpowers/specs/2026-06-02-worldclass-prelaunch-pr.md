作成日: 2026-06-02

## 第1部：海外サポーターへのお願い

### A. ローンチ前 — 初回依頼（〜6/8 想定）

#### A-1. 本人プロフィール
- 氏名・年齢・活動国/都市・所属（JICA/NGO/留学等）
- 顔写真3枚（屋外・室内・子どもたちと一緒）
- 自己紹介文（200〜400字）
- 身分証コピー
- 担当校・施設の所在地・連絡先
- 緊急連絡先（日本側の家族 or 所属団体）

#### A-2. 先生図鑑用コンテンツ（本人について）
- 自己紹介動画 60秒（縦型・自撮り）
- 活動風景写真 10枚以上
- 質問回答シート 5問
  1. なぜこの国・この活動を選んだか（200字）
  2. 一番心が動いた現地でのエピソード（300字）
  3. 日本の子どもに伝えたいこと（150字）
  4. 50%の支援金でまず何を届けたいか
  5. 日本にいた頃の自分に言いたいこと
- ウェイトリスト登録者へのお礼動画 30秒（特典用）

#### A-3. 教室図鑑用コンテンツ（担当クラスについて）
- 集合写真3パターン（教室内・校舎前・活動中）
- 校舎・教室・校庭の写真 10枚
- クラス全員で「こんにちは」動画 30秒（現地語＋英語）
- クラスの1日スケジュール（箇条書き）
- クラスから日本のクラスへの質問 1つ（音声＋翻訳）
- クラス全員が描いた「日本のイメージ」絵の写真
- 担任の先生からの一言コメント（テキスト or 動画）
- クラスで歌う歌・遊び 1つ（セッションで再現可能なもの）

**重要原則**：教室図鑑は **個人ではなくグループ** が主役。個別エピソード・氏名・顔アップは集めない。

#### A-4. 同意書・許諾書
- 校長同意書（教室図鑑掲載・物資レポート用／校長＋担任＋PTA代表の3者立会いサイン／日英＋現地語）
- 本人の肖像権・SNS引用許諾書
- 二次利用範囲の同意（プレスリリース・LP・自治体営業資料）

### B. 運用開始後 — 継続依頼

#### B-1. セッション運営
- 対応可能曜日・時間帯（現地時間／日本時間）
- ネット回線速度のスクショ・予備回線の有無
- 機材（PC・カメラ・マイク・三脚）の確認写真
- 停電・通信断時のバックアップ手順への同意
- セッション前日チェックリスト遵守
- 緊急時の代理対応（同僚への引き継ぎ）

#### B-2. 物資支援レポート（月次）
- 開封写真／配布シーン／使用後の様子 の3点セット
- 校長 or 担任からのサンクスレター
- 領収書スキャン（何が何個・いくら）
- 月次レポート提出（Googleフォーム・5分で完了）

#### B-3. 広報協力（継続）
- セッション中の現地側映像の別カメラ撮影
- 個人SNS（Instagram/X等）での月◯回投稿協力
- 公式アカウントへの素材提供同意（リポスト許可）
- note・ブログでの体験記寄稿（月1本／編集はHQ）
- 帰国時のオフライン報告会・学校訪問への登壇
- 他の現地日本人活動者の紹介（リファラル）
- 在外邦人コミュニティへの告知協力
- メディア取材対応（オンラインのみ・サポーター経由）

#### B-4. フィードバックループ
- セッション後アンケート提出（毎回・5分）
- 月1サポーターMTG参加（Zoom・HQと改善議論）
- Discord/Slack の改善提案チャンネル参加

### 5. ウェイトリスト導線（特典なし・通知のみ）

プロフィールリンク → 既存LPの優先案内枠 → メアド取得：

- 特典は設けない（ブランド純度を保つ：「50%支援に回る」ミッションに割引が並ぶ矛盾を回避）
- 訴求は **「ローンチ時に最初にお知らせします」のみ**
- **ローンチ前日に1通だけリマインドメールを配信**（これが唯一のメール接点・必須）
  - 内容：ローンチ日時／先着枠の案内／申込みURL
  - ツール：Mailchimp無料枠 or formrun（30分で設定）

### 6. 有料広告（W4以降・最小投資）

- Meta広告（Instagram）：日予算 1,000〜2,000円
- 配信先：教育関心層・30〜45歳女性・東京/大阪/福岡
- クリエイティブ：高エンゲージの教室図鑑投稿をそのままブースト
- CV計測：LPのウェイトリスト登録完了をピクセル設定（要：Meta Pixel ID）

### 7. KPI（特典なし運用に合わせた現実ライン）

| 指標 | 目標 |
|---|---|
| フォロワー | 1,000〜1,500 |
| ウェイトリスト登録 | 30〜50件 |
| 教室図鑑リール再生 | 3,000+/件 |
| 投稿あたり保存数 | 30+ |
| Meta広告CPA | 500円以下 |

数より質を優先。30人が確実に初週予約する方が、200人いて10人しか来ないより良い。

### 8. セーフガーディング・ポリシー（教室図鑑グループ運用版）

| 項目 | ルール |
|---|---|
| 同意 | 校長＋担任＋PTA代表 の3者同意で施設単位カバー |
| 名前 | 学校名は公開可／地名は市区町村まで・住所/座標非公開 |
| 顔 | クラス集合写真OK／個別アップは原則NG（手元・後ろ姿で代替） |
| 個人エピソード | 出さない。語るのは常に「このクラスでは」「みんなで」 |
| 制服・校章 | 出してOK（学校の誇りとして演出） |
| 取り下げ | 学校長申し出で24時間以内に削除 |
| 経済描写 | 個別の家庭事情には触れない／物資支援は施設単位で語る |
| 再同意 | 年1回・進級時に再確認 |

### 9. リスクと回避

| リスク | 回避策 |
|---|---|
| 「貧困ポルノ」批判 | 個人エピソード排除・夢/好き/得意で語る／集合写真ベース |
| 個人特定→現地トラブル | 学校名は市区町村まで・住所/座標非公開 |
| 同意の質が担保できない | 校長同意書を3者立会いサイン・現地語併記 |
| ワンオペ破綻 | Canvaテンプレ1つで6回流用・依頼テンプレ統一 |
| 顔出しNG児がいる | 手元・後ろ姿・絵・声で構成（世界観として成立） |
| メディア取材時の追加リスク | 取材はオンラインのみ・サポーター経由に限定 |

## 第5部：マネタイズ方針

### 基本スタンス
- **物資支援50%は維持**（ミッションの根幹）
- **赤字回避を優先**、創業者の収益化は当面後回し
- 創業者個人の生活費は別収入で確保する前提
- サービスは「赤字にならない範囲で社会貢献最大化」を目指す

### 単価10,000円セッションの想定収支
| 項目 | 金額 |
|---|---|
| 売上 | 10,000円 |
| Stripe手数料（3.6%） | -360円 |
| 物資プール（50%） | -5,000円 |
| インフラ | -200円 |
| サポーター報酬 | 0円（受取不可・後述） |
| 残り（運営） | 約4,440円 |

### 物資調達方針
- **現地調達優先**（日本からの輸送費を回避）
- 日本からの発送は「現地で調達できないPC・プロジェクター等」に限定し、別途設計
- 現地調達なら プール5,000円 → 4,000〜4,500円分の物資が届く（85〜90%効率）

### 広報での料金訴求
- LP・Instagramでは「料金の50%が物資支援に」と明記してよい
- 残り50%の内訳（運営・インフラ・Stripe等）は別途透明性レポートで開示

## 第6部：サポーター契約・JICA関連方針

### サポーター契約の建付け（個人ボランティアモデル）

WorldClassは **「JICAという組織」と契約せず、現地に住む個人と直接契約する**。
これによりJICA規約への抵触リスクを構造的に回避する。

### サポーター本人の責任を明文化

サポーター申込フォームに以下のチェックボックスを必須項目として配置：

```
□ 私は、所属する組織・プログラム・在留資格・受入機関の規約上、
  このような個人活動への参加が許可されていることを
  自己責任で確認しています。

□ 私はWorldClassからいかなる金銭報酬も受け取らないことに同意します。
  物資支援は私個人ではなく、私が活動する現地校・施設に届くことを
  理解しています。

□ WorldClassは、私の所属組織との関係について
  一切関与しないことを了承します。
```

### 契約書の核となる条項
- サポーターは **個人として** 文化交流活動に参加するボランティア
- WorldClass と サポーターの間に **雇用関係・業務委託関係は存在しない**
- サポーターの主たる活動は別途あり、WorldClassへの協力は **本人の自由意志による無償行為**
- 物資支援は **WorldClass → 現地校** への直接寄付であり、サポーターは経由しない

→ これで労務関係・税務関係・所属組織規約 すべてから切り離す。

### 募集チャネルと表現の使い分け

**OK（内部・募集チャネル）：**
- JICA OB/OG会、二本松/駒ヶ根訓練所同期会経由で声掛け
- 現役隊員に個人として参加可能か本人判断してもらう
- 在外邦人コミュニティ（FB群）、NGO駐在員、留学生組織

**NG（対外発信）：**
公式チャネル・LP・Instagram・プレスリリースで **JICA関連用語を一切使わない**。

| ❌ NG表現 | ✅ OK表現 |
|---|---|
| JICA協力隊経験者 | 現地で活動する日本人 |
| 青年海外協力隊OB/OG | 在外邦人ボランティア |
| JICAネットワーク | 現地在住の日本人ブリッジパートナー |
| 「JICA協力隊・◯◯さん」 | 「ケニア在住・◯◯さん」 |
| 「元青年海外協力隊」 | 「元教師・現在◯◯で活動中」 |
| 「JICAでの活動歴3年」 | 「現地での活動歴3年」 |

サポーター本人が個人SNSでJICA肩書きを名乗ることは自由だが、**WorldClass公式チャネルでは触れない**。

### 募集文言ルール
募集ページ・Instagramで「JICA協力隊員の方歓迎」とは書かない。
**「現地で活動する日本人ならどなたでも」** と表現する。
結果的にJICA関係者が多くなっても、それは公表しない。
