## 3. SNS戦略（Build in Public）

### メインチャネル

**Instagram 優先**（保護者層・写真強み）

### 訴求軸

- **英語教育軸**：子どもが英語で海外とつながる体験
- **社会貢献軸**：支払いが途上国の物資支援になる

### コンテンツ方針

1. 現地写真・物資支援レポート（メイン）
2. 体験レポート（セッション後の子どもの反応）
3. Build in public（作ってる過程・なぜ作るのか）

### 投稿順序

1. **1本目**：「なぜWorldClassを作るのか」
   - 構成：チュニジアで見たもの → 日本の子どもに足りないもの → だから作る
2. 以降：現地写真・物資支援レポート
3. 慣れたら：体験レポート・動画（リール）

## 4. 海外校確保フロー

### ルート

現役海外協力隊員経由（直接コネあり）

### フロー

```
1. 現役隊員にDM（SNS/直接連絡）
2. 「活動先の学校・教師を紹介してほしい」と依頼
3. 紹介 → 学校・教師に直接打診
4. 初期目標：1〜3校確保
```

### 打診条件

- 教師報酬：無償
- 代わりに学校単位で物資支援（教師も恩恵）
- セッション頻度：週1〜2回程度
- 対応言語：英語のみ

---

## 5. 物資支援の仕組み

- セッション料金の50%を物資ポイントとして海外校ごとにプール
- 学校単位で管理（教師個人・学校全体 一体）
- 四半期/半年に1回まとめて手配（現地調達優先）
- 現金のやり取りなし
- 受領確認写真 → 日本側ユーザーへ通知（SNS発信ネタにもなる）

## 6. 塾・民間営業戦略

### アポ獲得方法

- **1件目**：知り合いの塾 → MVP完成後に打診
- **2件目以降**：SNS経由（build in publicで塾関係者が自然流入）
- 飛び込み・電話なし

### タイミング

MVP完成後（動くものを見せてから営業）
