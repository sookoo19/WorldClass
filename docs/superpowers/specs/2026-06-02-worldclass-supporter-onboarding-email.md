## 運用メモ

### 送信前チェックリスト
- [ ] サポーター氏名を正しく差し替え
- [ ] 創業者署名（氏名・連絡先）を記入
- [ ] Googleドライブ共有フォルダを作成・URLを本文に追記
- [ ] 添付4点が揃っているか確認
- [ ] JICA・協力隊などの語が本文・添付に残っていないか grep で最終確認
- [ ] 個別の子どもの撮影・公開がNGである旨が複数箇所で強調されているか

### 送信後のフォロー
- 送信から24時間以内に既読確認（返信 or Slack/LINE）
- 6/5(木)時点で素材アップロード未着の人にリマインド
- 6/8(日)夕方に必須素材の最終確認・遅延者と個別調整
- ティア2は6/15まで・必須ティアが揃っていれば公開開始可能

### リスクと対応
| リスク | 対応 |
|---|---|
| 6人中、必須素材未提出が発生 | 公開順を入れ替え・揃った人から先行公開 |
| 校長同意書が間に合わない | クラス紹介を後ろ倒し・本人紹介のみ先行 |
| 「JICAと書いてほしい」要望 | 個人SNSで自由に発信可・公式チャネルでは原則不可と説明 |
| 個別の子どもの素材が紛れ込む | 公開前確認で除外・サポーターに再周知 |
